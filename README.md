# Ajine NFT Website

React + Vite public website shell for Ajine NFT.

## Local development

```bash
npm install
npm run dev
```

## Render Static Site

- Repository: `testingthechange/nft`
- Build command: `npm install && npm run build`
- Publish directory: `dist`
- Custom domain: `ajinenft.online`

This initial website is informational only. Directus, Polygon, wallet verification, authentication, and purchasing are **not yet connected**. Do not put API secrets or signing keys in Vite environment variables.
